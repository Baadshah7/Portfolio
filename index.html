Child Monitoring System

A dual-app Android system enabling parents to monitor their child's device activity in real time via a secure linking code.

PROBLEM

Parents lack real-time visibility into their children's mobile activities and location data, creating significant safety risks in unsupervised environments.

SOLUTION

A dual-app Android framework connecting Parent and Child devices via a secure pairing code (M-Code) to sync call logs, messages, contacts, and GPS data.

USB Write Blocker

A hybrid hardware-software digital forensics solution designed to prevent forensic media alteration during data acquisition.

PROBLEM

Connecting suspect storage media directly to forensic analysis hosts alters timestamps or metadata, compromising the legal admissibility of evidence.

SOLUTION

An Arduino-based hardware blocker that intercepts write operations, integrated with a Python daemon for secure, read-only device mounting in Kali Linux.

Python Arduino Uno Kali Linux Digital Forensics
